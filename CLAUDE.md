# SoftWater Assist Railway

This is the Railway version of the educational app. Next.js App Router, TypeScript, Tailwind, Prisma 6, PostgreSQL. Railway automatically deploys from the main branch of this GitHub repository. The database is Railway PostgreSQL, accessed only through the DATABASE_URL environment variable — never hard-code credentials. Do not set up a local database or start a local server. AI responses are simulated; no paid LLM service or API key is required. Attachment handling stores filename and size only. Do not claim that custom prompt text or sliders control real inference.

Read ENVIRONMENT.md before using the local runtime. Use pnpm, as configured in this project. Before every push, run pnpm test and pnpm build; do not push if either fails. Startup applies committed Prisma migrations and idempotently seeds default personas before starting Next.js on PORT. Never commit .env or secrets. After each completed task, commit and push the relevant changes so Railway deploys the new version; commit, push and merge only as authorized by the user. Do not overwrite the separate SoftWater-Assist local demo.

This is a shared public classroom demo without authentication: every visitor can read, change or delete shared conversations and custom personas. Do not present it as a private customer portal. Keep the shared-data notice visible. Default personas can be edited but cannot be deleted.
